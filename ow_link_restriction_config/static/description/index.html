Overview

Restrict internal navigation, one model at a time

Internal Link Restriction lets an administrator choose which models should have their Many2one fields' "Internal link" click-through disabled — the hover arrow and clickable value that jump straight to the linked record's form. Add a model to the list, keep it Active, and every Many2one field on that model's Form and List views stops being clickable. Untick Active any time to pause the restriction without losing the configuration.

This is a focused UI restriction, not a data security rule. It stops casual click-through navigation on sensitive relations — like Employee or Department fields in HR views — without touching record access rights or record rules. Kanban views are always excluded by design, so day-to-day navigation elsewhere in Odoo stays exactly as it was.

🎯 Per-Model Configuration
Add any model from ir.model to the restriction list — no view inheritance required.
🖱️ Click-Through Disabled

🗂️ Form & List Scoped

A UI restriction, not a substitute for ir.rule or access rights.

Workflow

How a restriction takes effect

1
Add a model to the list
Open Internal Link Restrictions and pick the model you want to lock down.
2
Leave Active checked
The model is queued for restriction the moment the entry is saved.
3
Refresh the browser tab
The active restriction list loads once per session, at login or page load.
4
Verify on Form & List
Many2one fields on that model lose their open-record arrow; Kanban stays normal.
5
Untick Active anytime
Pause the restriction whenever needed without losing the configuration entry.
Setup

Install and restrict your first model

1
Install the module
Copy the module into your Odoo addons path, update the app list, then install Internal Link Restriction from Apps.
2
Open Internal Link Restrictions
Go to Tefugen Tools → Internal Link Restrictions (visible to the Settings / Technical Features group).
3
Add your first model
Pick a model, keep Active checked, save, then refresh your browser tab to apply it.
