Overview

One workspace for role-based access administration

Access Management Pro turns scattered Odoo security configuration into clear, reusable profiles. An administrator can collect users, existing security groups, model permissions, record domains, hidden menus, and field-view policies inside one profile and apply it from one screen.

The module creates normal Odoo security groups, access-control entries, and record rules. Your technical team can inspect the generated records with familiar Odoo tools, while functional administrators get a simpler workflow and a permanent application history.

✓ Faster onboarding
Assign a tested role profile to new employees without rebuilding permissions user by user.
✓ Consistent security
Reuse the same approved access pattern across users performing the same job.
✓ Clear responsibility
See the users, policies, last application time, and responsible administrator together.
✓ Cleaner workspaces
Remove menu branches that do not belong in a role's everyday navigation.

Workflow

From policy design to applied access

1
Create the role profile
Give the profile a clear business name and describe who should receive it.
2
Choose users and included groups
Assign one or many users and reuse existing Odoo security groups where appropriate.
3
Configure permissions and visibility
Add model permissions, record-rule domains, hidden menu branches, and field UI policies.
4
Apply and audit
Apply the profile to synchronize users and native security records. The event is added to the audit trail automatically.
Security architecture

Built on the Odoo mechanisms your team already knows

Applied profiles create and update native res.groups, ir.model.access, and ir.rule records. The generated security remains inspectable and compatible with normal Odoo administration.

Server-side controls
Model ACLs and record rules enforce data access through Odoo's normal ORM security.
Interface controls
Menu and field policies create cleaner role-specific views in the standard web client.
Honest policy boundary
Field UI policies should be combined with ACLs or record rules whenever server-side protection is required.
Setup

Install and begin with a controlled pilot

1. Install the module
Copy it into the addons path, update Apps, and install Access Management Pro.
2. Open Access Pro
System administrators automatically receive the Access Management Manager role.
3. Build a test profile
Start with a test user and a small set of permissions on a staging database.
4. Apply and verify
Log in as the assigned user and verify menus, CRUD operations, and record domains.
