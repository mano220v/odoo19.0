# Access Management Pro

Access Management Pro provides reusable security profiles for Odoo 19. Each profile can assign users to native groups, generate model ACLs and record rules, hide menu branches, apply field UI policies, and record application events.

## Setup

Open **Access Pro → Access Profiles**, create a profile, select users, configure policies, then select **Apply Security Profile**. Model permissions and record rules are enforced by native Odoo security. Field policies change standard views and should be combined with ACLs or record rules when server-side protection is required.
