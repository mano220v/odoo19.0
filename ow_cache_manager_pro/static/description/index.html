Overview

The complete storage command center

Cache & Storage Manager Pro takes the same two genuinely safe cleanup mechanisms as the free edition — regenerable web asset bundles and orphaned junk attachments — and wraps them in a full analytics dashboard: a donut-chart storage breakdown, a searchable/age-filterable drill-down file browser, a Top Storage Consumers table showing which models are eating the most space, and a Duplicate Record Finder for attachments sharing identical file content.

On top of that, an optional daily Auto-Clean scheduler keeps things tidy automatically (asset cache + junk only — duplicates and live data are never touched without a manual review), a full Cleanup History logs every action for audit, and a one-click Excel Export produces a downloadable report whenever you need one.

🍩 Visual Storage Dashboard
Donut chart, live totals and PostgreSQL database size, all from one Generate click.
🏆 Top Storage Consumers
A ranked table of which models/apps are using the most filestore space.
🧬 Duplicate Record Finder
Groups attachments by checksum and lets you keep the newest, remove the rest.
📜 Audited Auto-Clean
Daily scheduled cleanup plus a full Cleanup History log of every action taken.

Workflow

How the dashboard keeps your storage lean

1
Generate a full scan
One click populates the donut chart, top consumers, duplicate groups and DB size.
2
Drill into any category
Search by name, filter by age, then select and delete individual files with confidence.
3
Review duplicates & top consumers
Keep the newest copy in each duplicate group; see which models are worth investigating.
4
Turn on Auto-Clean (optional)
A daily cron then clears asset cache and junk automatically — no manual step needed.
5
Audit and export anytime

Setup

Install and configure Pro

1
Install the module
Copy the build matching your Odoo version (17.0, 18.0 or 19.0) into your addons path, update the app list, then install Cache & Storage Manager Pro from Apps.
2
Optional: install xlsxwriter
Only needed for Excel Export: pip install xlsxwriter on the Odoo server.
3
Open the dashboard and Generate
Go to Cache Manager Pro → Dashboard, click Generate, then optionally enable Auto-clean daily.
