Getting started

Install, open, get moving

1
Install Premium Accounting Dashboard
Install from Apps. The module depends on Odoo's standard Accounting and Web apps.
2
Open Finance Studio
Find the separate Finance Studio app in the Odoo app menu. Access is limited to accounting-read and invoice groups.
3
Choose a period and drill down
Select Month, Quarter, Year or All time. Click a KPI or document to open the matching Odoo records.
