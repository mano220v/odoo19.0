Word Editor for Odoo

A full-featured, Word-like document processor built natively inside Odoo — write, format, collaborate and export without ever leaving your ERP.

What is Word Editor?

Word Editor brings a professional document-processing experience directly into your Odoo instance. Create, edit, and manage business documents with a familiar Word-style interface — complete with a rich formatting toolbar, A4 page layout simulation, real-time auto-save, and one-click export to Microsoft Word (.docx) and PDF.

No third-party subscriptions. No browser extensions. Everything lives inside Odoo, next to your data.

🚀 Key Highlights

  • Full WYSIWYG editor with A4 paper layout simulation
  • Export to .docx (Microsoft Word) and PDF
  • Auto-save every 3 seconds — never lose your work
  • 4 built-in templates: Letter, Meeting Notes, Project Report, Invoice
  • Find & Replace across the entire document
  • Chatter integration — comment and track changes on every document
  • Role-based access control (User / Manager)

Installation

1. Install the Module

Download and unzip into your Odoo addons path, then install via Apps → Word Editor.

2. Optional — Enable DOCX Export

For native .docx export, install the Python libraries on your server:

pip install python-docx beautifulsoup4

Without these libraries, the module still works fully — DOCX export falls back to an HTML download. All other features (PDF export, editing, auto-save, templates) are unaffected.

3. Set User Permissions

Go to Settings → Users, open a user record, and set the Word Editor access level to User or Manager.
