Overview

Professional document editing inside Odoo

Word Editor brings a professional document-processing experience directly into your Odoo instance. Create, edit, and manage business documents with a familiar Word-style interface, A4 page layout simulation, automatic saving, document templates, and export options for Microsoft Word (.docx) and PDF.

No external subscriptions. No browser extensions. Your documents remain inside Odoo together with your users, permissions, chatter, and business data.

📝 Word-like Editing Interface
A full-screen editor with formatting toolbar, page layout, rulers, zoom, templates, and live document statistics.
💾 Auto-Save & Save Status
Changes are saved automatically every 3 seconds, with a clear status indicator showing the latest save state.
📋 Templates & Document Manager
Create documents from Blank, Business Letter, Meeting Notes, Project Report, or Invoice templates. Manage them in kanban, list, and form views.
🔒 Odoo Security & Chatter
Use Odoo access groups, ownership rules, followers, activities, chatter, tags, categories, and status workflow.

Setup

Install and start editing

1
Install the module
Copy the module into your Odoo addons path, update the app list, then install Word Editor from Apps.
2
Optional DOCX libraries
For native .docx export, install python-docx and beautifulsoup4 on the server. Without them, the editor still works and DOCX export can fall back to HTML download.
3
Set permissions
Go to Settings → Users and assign Word Editor access as User or Manager.
