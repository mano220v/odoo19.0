Overview

Stop downloading files just to see what's inside

Every "Print" click downloads a PDF you only wanted to glance at. Every Excel attachment means download → open → check → close → delete. QuickGlance Preview removes both round trips. Click Print and see the report immediately, with Download available only if you actually need the file. Click an Excel, CSV or ODS attachment and read it inline, sheet tabs and all.

📄 Preview Before Print Downloads
Hooks Odoo's own official ir.actions.report handlers registry — the same extension point Odoo itself uses — so it stays reliable across upgrades.
📊 Client-Side Spreadsheet Parsing
Excel, CSV and ODS files are parsed entirely in the browser — no LibreOffice, no unoconv, nothing to configure on the server.
🧩 Works on Any Binary Field
One widget attribute adds a Preview button anywhere a file is uploaded — even before the record is saved.
📁 Attachment Lists, Covered
A Preview button appears next to every previewable file under Settings → Technical → Attachments, and anywhere else ir.attachment shows up.
Features

Everything included — nothing to configure

📄 Report Preview Handler
Registers into Odoo's own ir.actions.report handlers extension point rather than patching internal, undocumented widgets. Works on any qweb-pdf report — invoices, quotations, delivery slips, or your own custom reports — with zero extra configuration.
📊 Safe Spreadsheet Rendering
Spreadsheets are parsed with a bundled parser and rendered as a plain table using Odoo's own auto-escaping — never as raw injected HTML. A crafted spreadsheet cell can't run script in your browser just because you previewed it.
🧩 Universal Binary Field Widget
Add widget="quickglance_preview" to any Binary field, in any module's view. It extends Odoo's own Binary field component, so upload / replace / delete keep working exactly as before — Preview is simply added alongside them.
📁 Attachment List & Form Button
A Preview button is added to the standard attachment list and form views — no new model, no extra access rules, works immediately after install.
🛡️ Large-File Safeguard
Spreadsheet previews are capped at 500 rows / 60 columns so a huge file can't freeze the tab — the full data is always one Download click away.

FAQ

Frequently asked questions

Does this work on both Community and Enterprise?
Yes. It depends only on web and mail, both present in every Odoo edition and version we support (17.0, 18.0, 19.0).
Odoo 19 already previews PDFs in the chatter — why do I need this?
Odoo 19's native chatter preview only covers PDF attachments you've already uploaded. It does not preview Excel, CSV or ODS files (clicking one currently does nothing), and it does not intercept the Print button on reports. QuickGlance covers both of those — and adds full PDF-report-preview-before-download for 17.0 and 18.0, where chatter PDF preview isn't native yet.
Do I need LibreOffice or any conversion server for Excel preview?
No. Spreadsheets are parsed entirely in the browser using a bundled library — nothing to install or configure on your server.
Can an automated print (server action, automation) skip the preview?
Yes. Add qg_skip_preview: True to that action's context and QuickGlance will let it download normally, uninterrupted.
Will this break my existing Binary fields or custom views?
No. The field widget extends Odoo's own Binary field rather than replacing it, and only applies where you explicitly add widget="quickglance_preview". Every other Binary field in your database is untouched.
