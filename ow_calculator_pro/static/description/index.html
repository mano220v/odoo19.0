Overview

One calculator workspace, right inside Odoo

Calculator Pro replaces the browser tab you keep open for quick math with a native Odoo app. Switch between eight dedicated calculators from one sidebar, and every result is saved to your personal history automatically — searchable, filterable, and exportable like any other Odoo record.

Currency conversions use Odoo's own currency rate tables, so results always match your invoices and sales orders. A live dashboard shows usage trends at a glance, and everything runs on native Odoo security — no external service, no separate login, no subscription.

🧮 Eight Calculators
Standard, scientific, currency, unit, loan/EMI, date, BMI, and discount/tax — one interface for all of them.
💱 Odoo-Native Currency Rates
The currency converter reuses Odoo's own multi-currency engine, so conversions stay consistent with the rest of your database.
📊 Live Usage Dashboard
KPI cards, a 14-day activity chart, and a breakdown by calculator type in one operational view.
🔒 Native Odoo Security
Every user sees only their own history and favorites by default; an optional admin group can review all activity.

Setup

Install and start calculating

1
Install the module
Copy the module into your Odoo addons path, update the app list, then install Calculator Pro from Apps.
2
Open the app
Go to the Calculator app from the main menu — every internal user gets access automatically.
3
Fine-tune the settings
Go to Settings → Calculator to set decimal precision, history retention, and the default theme.
