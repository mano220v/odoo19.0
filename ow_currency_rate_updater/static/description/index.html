Why this module

Odoo's built-in currency update is a single button buried in Accounting settings, with no history, no trend visibility, and no way to schedule it in the background per company. If your business bills or pays in more than one currency, you either remember to click that button daily, or your rates drift.

Live Currency Rate Updater fetches real exchange rates from free, key-free sources (Frankfurter.app or the official European Central Bank feed) — or any custom JSON rate API you already pay for — and writes them straight into Odoo's native res.currency.rate model, so Accounting, Sales, Purchase and Invoicing pick the new rates up immediately. A dedicated dashboard shows exactly what changed, by how much, and when it last ran.

Features

🌍 Choice of live providers
Frankfurter.app (free, no key, sourced from the ECB) or the official ECB XML feed — both work out of the box. Or point it at any API that returns a JSON rates object.
📈 Trend cards with sparklines
Every currency gets a card showing the current rate, a colour-coded up/down badge versus the previous rate, and a 14-point sparkline of recent history.
🔍 Sortable table view
Switch to a dense table, search by currency code or name, and sort by rate or by percentage change to spot the biggest movers instantly.
⏱ Configurable auto-sync
Pick an interval from hourly to once a day, per company. A single scheduled action checks every company and only fetches when each one's interval is actually due.
🖱 One-click manual sync
"Sync Now" on the dashboard fetches immediately, shows a live spinner, and confirms with a success or error notification — no waiting for the next scheduled run.
🧾 Full sync audit log
Every run — manual or scheduled — is logged with provider, duration, number of currencies updated, and the exact error message on failure.

How it works

1
 Configure once
Pick a provider, set the update interval, and enable auto-sync in Currency Rates → Configuration → Settings.
2
 The scheduled action checks in hourly
For each company with auto-sync on, it fetches fresh rates only once that company's configured interval has actually elapsed.
3
 Rates land in Odoo's native model
Each fetched rate is written to res.currency.rate for the day, so every other Odoo app sees it instantly.
4
 Check the dashboard any time
Open Currency Rates → Dashboard to see current rates, trends, and click Sync Now whenever you need the very latest figures.

Setup

  1. Install Live Currency Rate Updater from Apps.
  2. Make sure the currencies you need are activated under Accounting → Configuration → Currencies.
  3. Go to Currency Rates → Configuration → Settings, choose a provider (Frankfurter.app needs nothing else; ECB works out of the box; Custom API needs a URL and, optionally, a key).
  4. Set your preferred update interval and enable auto-sync.
  5. Open Currency Rates → Dashboard and click Sync Now once to pull the first set of live rates.
