Overview

Rates that update themselves, wherever your business bills

Odoo's built-in currency update is a single button buried in Accounting settings, with no history, no trend visibility, and no way to schedule it in the background per company. Currency Converter fetches real exchange rates from free, key-free sources (Frankfurter.app or the official European Central Bank feed) — or any custom JSON rate API you already pay for — and writes them straight into Odoo's native res.currency.rate model, so Accounting, Sales, Purchase and Invoicing pick the new rates up immediately.

A dedicated dashboard shows exactly what changed, by how much, and when it last ran — and every run, manual or scheduled, is captured in a full sync audit log so failures never happen silently.

Workflow

How a scheduled sync runs

1
Configure once
Pick a provider, set the update interval, and enable auto-sync in Currency Rates → Configuration → Settings.
2
The scheduled action checks in hourly
For each company with auto-sync on, it fetches fresh rates only once that company's configured interval has actually elapsed.
3
Rates land in Odoo's native model
Each fetched rate is written to res.currency.rate for the day, so every other Odoo app sees it instantly.
4
Check the dashboard any time
Open Currency Rates → Dashboard to see current rates and trends, and click Sync Now whenever you need the very latest figures.
Setup

Install and sync your first rates

1
Install the module
Install Currency Converter from Apps.
2
Activate the currencies you need
Under Accounting → Configuration → Currencies — only active currencies show up on the dashboard and get synced.
3
Choose a provider
In Currency Rates → Configuration → Settings: Frankfurter.app needs nothing else, ECB works out of the box, Custom API needs a URL and, optionally, a key.
4
Set the interval and enable auto-sync
Choose how often rates should refresh, from hourly to once a day.
5
Sync Now
Open Currency Rates → Dashboard and click Sync Now once to pull the first set of live rates.
