Overview

A complete audit trail for every file that leaves your database

Compliance teams, IT admins and managers often need to answer one simple question: "who downloaded this?" Download History Manager answers it automatically, for every attachment, report and data export — without touching a single existing workflow. It hooks into a version-stable extension point that runs after every request, so it works regardless of which controller served the file.

Every entry records the user, exact timestamp, file name, size and mime type, IP address, and the source record — with a one-click link back to it. Two access levels keep the log itself under control: regular users can optionally see only their own downloads, while managers see the complete company-wide history.

Workflow

How a download gets logged

1
Install the app
Add Download History Manager from the Apps menu. No configuration is required to start.
2
Users work as usual
Anyone downloads an attachment, prints a report, or exports a list to XLSX/CSV — exactly as before.
3
It's logged instantly
The download is recorded in the background with the user, file, source record and timestamp.
4
Review anytime
Open the Download History menu to search, filter, group, or analyze the full history on a dashboard.
Setup

Install and start tracking downloads

1
Install the module
Copy the module into your Odoo 19 addons path, update the app list, then install Download History Manager from Apps.
2
Optionally set a retention period
Under Settings → Download History, set how many days of history to keep. Leave the default, or set 0 to keep records forever.
3
Nothing else to do
Every attachment, report and export download is logged from this point on — open the Download History menu anytime to review it.
