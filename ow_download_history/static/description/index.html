Compliance teams, IT admins and managers often need to answer one simple question: "who downloaded this?" Download History Manager answers it automatically, for every attachment, report and data export — without touching a single existing workflow.
⬇

Fully Automatic Logging

No buttons to click, no workflow to change. Every real download is captured silently in the background the moment it happens.

Every Download Channel

Who, What & When

How it works
Install it, and it just works. There is nothing to configure to get started.
1

Install the app

Add Download History Manager from the Apps menu. No configuration is required.

2

Users work as usual

Anyone downloads an attachment, prints/downloads a report, or exports a list to XLSX/CSV — exactly as before.

3

It's logged instantly

The download is recorded in the background with the user, file, source record and timestamp.

4

Review anytime

Open the Download History menu to search, filter, group, or analyze the full history on a dashboard.

What gets tracked, per download
Field Description
Downloaded ByThe Odoo user who triggered the download.
Download DateExact date and time the file was downloaded.
File Name & TypeOriginal file name, and whether it's an attachment, image, report, or data export.
File Size & Mime TypeSize in a human-readable format (KB/MB) and the file's mime type.
Source RecordThe model and record the file belongs to (e.g. an invoice, a project task), with a one-click link back to it.
IP AddressThe IP address the download request came from.
