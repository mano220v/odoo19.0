Track who downloaded which file, from which record, and when — across
attachments, printed/downloaded reports, and data exports. Fully
automatic, nothing to configure.

**Table of contents**

.. contents::
   :local:

Features
========

* Automatic logging of attachment, report, and data-export downloads.
* Records user, timestamp, file name/size/mime type, IP address, and the
  source record (with a one-click link back to it).
* List, search, pivot and graph views for investigation and analytics.
* Two access levels: "own downloads only" for regular users, full access
  for managers.
* Configurable automatic cleanup (data retention) plus a manual
  "Clear Old History" wizard.

Configuration
=============

Go to *Download History > Configuration > Settings* to set the
retention period (in days). Set it to ``0`` to keep history forever.

Usage
=====

Nothing to do — install the module and every attachment/report/export
download made through the standard Odoo UI is logged automatically.
Open *Download History* from the main menu to review it.
