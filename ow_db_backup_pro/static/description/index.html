Overview

Backups that run themselves, wherever you keep them

Automatic Database Backup Pro lets an administrator create one or more backup configurations, each with its own schedule, storage destination, retention policy and alert list. Once saved, a scheduled action runs quietly in the background — dumping the database (with or without the filestore), optionally encrypting it, uploading it to the chosen destination, and cleaning up older backups according to the retention policy you set.

Every run is logged in the Backup History, with size, duration, destination and — if something goes wrong — the full error trace, so failures never happen silently. Local backups can be downloaded straight from the list, and any successful backup can be restored with one click into a brand-new database, never overwriting a live one.

Workflow

How a scheduled backup runs

1
Create a configuration
Choose the database, backup format (full or SQL-only), destination and schedule.
2
Test the connection
One click confirms credentials work before anything is scheduled to run.
3
Save — the schedule takes it from here
A Scheduled Action is created and kept in sync automatically; no manual cron editing.
4
Monitor Backup History
Every run logs its status, size, duration and destination — failures include the full trace.
5
Restore when you need it
One click restores any successful backup into a brand-new database — your live data is never touched.
Setup

Install and schedule your first backup

1
Install the module
Copy the module into your Odoo addons path, update the app list, then install Automatic Database Backup Pro from Apps.
2
Install optional libraries as needed
Only for the destinations you'll use: paramiko (SFTP), boto3 (S3), dropbox, google-api-python-client + google-auth (Drive), pyzipper (encryption).
3
Create your first configuration
Go to DB Backup Pro → Configurations, set a destination and schedule, then click Test Connection and Backup Now.
