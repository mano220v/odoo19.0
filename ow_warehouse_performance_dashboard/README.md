# Warehouse Ops Center

A live warehouse operations control surface for Odoo 19.0.

## Features

- Due within 24 hours, overdue, ready to execute, and reservation-needed transfer metrics.
- Overdue work grouped by age: under 24 hours, 24–48 hours, and 48 hours or more.
- Outbound dispatch SLA compared with scheduled dates.
- Fourteen-day completed inbound, outbound, and internal movement trend.
- Exact open workload by operation type and a priority-sorted transfer queue.
- Optional active picking-batch count when batch transfers are installed.
- Replenishment watchlist, period filters, quick-create actions, and one-minute refresh.

Install the standard Inventory app, add this folder to the addons path, update the Apps list, and install **Warehouse Performance Dashboard**. Data respects the current user's standard Odoo access rights and record rules.
