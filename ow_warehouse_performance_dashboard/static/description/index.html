Overview

Warehouse work, exceptions and stock risk in one view

The dashboard reads your existing stock transfers, operation types and replenishment rules. Clickable indicators open the relevant Odoo records so supervisors can move from a signal to the work behind it without searching manually.

Shift control
Open work, due in 24 hours, overdue transfers, ready operations and outbound dispatch SLA.
Exception pressure
Age late work in 0–24, 24–48 and 48+ hour bands; track reservations and optional active picking batches.
Stock and flow
Review 14-day receipts, deliveries and internal movements, workload by operation type, and top replenishment suggestions.

Setup

Install and start using the dashboard

  1. Install the standard Odoo Inventory application.
  2. Add this module to your addons path, update the Apps list, and install Warehouse Performance Dashboard.
  3. Open the Warehouse Performance Dashboard menu and select a time window.
  4. Click any metric, queue row, workload bar or replenishment figure to open its related Odoo records.
The dashboard follows the current user's Inventory access rights. Batch indicators are shown when the optional stock picking batch model is available.
FAQs

Frequently asked questions

Does this create or replace stock operations?
No. It reads standard stock records and provides shortcuts to existing Odoo transfer workflows.
How often does the data refresh?
The dashboard refreshes automatically every minute and also has a manual refresh control.
Does it depend on a separate barcode or batch module?
No. Inventory is the required dependency. Picking batch counts appear only if the batch model is installed and accessible.
Does the dashboard bypass access rules?
No. It uses the signed-in user's standard Odoo access rights and record visibility.
