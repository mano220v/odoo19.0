Overview

Know exactly where your filestore space is going

Odoo has no single unified "cache size" like a mobile OS settings screen. Cache & Storage Manager targets the two real, safely-clearable Odoo mechanisms — regenerable web asset bundles and genuinely orphaned attachments — and adds a full storage breakdown on top, so you always know what is safe to remove before you remove it.

Every clear action reports exactly how much space was freed and how many files were involved. Nothing here ever touches live business data — orphaned-record detection only flags attachments whose linked record no longer exists in the database.

🧹 Two Safe Cache Types
Regenerable /web/assets/* bundles and genuinely orphaned attachments — never live data.
📊 Full Storage Breakdown
See Images, Videos, Documents, Audio and Other totals at a glance, like a mobile device manager.
📁 Click-Through File Lists
Click any category to open the underlying files, with a Junk vs Live-data badge on every row.
✅ Freed-Space Confirmation
Every clear action reports exactly how much space and how many files were removed.

Setup

Install and run your first scan

1
Install the module
Copy the module matching your Odoo version (17.0, 18.0 or 19.0) into your addons path, update the app list, then install Cache & Storage Manager from Apps.
2
Open the dashboard
Go to Cache Manager → Dashboard (visible to Settings/Technical users only).
3
Generate, review, then clear
Click Generate to scan, review the breakdown, then clear the asset cache, junk files, or drill into a category first.
