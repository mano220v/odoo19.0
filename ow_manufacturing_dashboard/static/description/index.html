Insights

Where the load is, and what's falling behind

📊 Work Center Workload
A ranked bar view of open job orders per work center. Click any bar to jump straight to that work center's queue.
🚨 Top Delayed Orders
The six most overdue manufacturing orders, oldest planned start first, with one click through to the record.
📈 7-Day Completed Orders Trend
A simple bar chart of finished manufacturing orders over the last week, rendered with Chart.js when available and a lightweight CSS fallback otherwise.
Setup

Up and running in two minutes

1
Install the module
Install Manufacturing Dashboard from Apps — it depends only on the standard mrp app.
2
Open the dashboard
Find it under the Manufacturing app menu. It loads live counts on open and refreshes automatically every 30 seconds.
3
Pick a period, click a card
Switch between Today / Week / Month / All, then click any KPI, work center, or delayed order to drill straight into the filtered list.
