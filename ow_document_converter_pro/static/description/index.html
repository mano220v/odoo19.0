Conversion engines

Free fallback and enhanced mode

LibreOffice

Required for DOC/DOCX to PDF. Runs headlessly on the Odoo server.

pdf2docx Enhanced

Optional engine that attempts to reconstruct PDF layout, tables, and images.

Built-in Free Mode

Uses pypdf and python-docx to create an editable text document without pdf2docx.

Server setup

Dependencies

sudo apt install libreoffice
pip install python-docx pypdf
# Optional enhanced PDF layout engine
pip install pdf2docx

Restart Odoo after installing Python packages. LibreOffice is only needed for Word-to-PDF. PDF-to-DOCX free text mode works without pdf2docx.

Transparent limitations

What to expect from PDF conversion

  • PDF describes positioned page content, so conversion cannot guarantee the original Word structure.
  • The built-in free engine prioritizes editable text and does not preserve complex tables, columns, fonts, or images.
  • The optional pdf2docx engine improves layout reconstruction but complex documents may still require editing.
  • Scanned/image-only PDFs require OCR before conversion; this module does not perform OCR.
  • Password-protected or damaged files may be rejected by the conversion engine.
