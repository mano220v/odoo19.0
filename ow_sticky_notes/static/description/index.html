Overview

Windows Sticky Notes, built into the Odoo backend

Sticky Notes adds a small, draggable ball to every screen of the Odoo backend — the same mechanism Odoo uses for the Discuss chat windows, so it's always there no matter where you navigate. Click it and a panel slides in from the right holding as many colour-coded notes as you like. Type and the note saves itself about half a second after you stop, with no save button to remember.

Notes are private per user, stored server-side, and follow you across devices and sessions — a dedicated record rule keeps every user scoped to their own. Pin the ones that matter, colour-code the rest, and optionally link a note to whatever record you have open so it resurfaces automatically the next time you're back on it.

🟡 Six Colour-Coded Notes

💾 Autosaves as You Type
No save button, no lost drafts — notes persist to the server automatically.

Workflow

How a note gets jotted down

1
Click the ball
Or press Alt+N from anywhere — the notes panel slides in from the right.
2
Add a note
Click the + button — a new note appears with a random colour, ready to type into.
3
Type — it saves itself
No save button; the title and content autosave about half a second after you pause.
4
Colour, pin, or link it
Pick a swatch, tap the pin to keep it on top, or tap the link icon to tie it to the open record.
5
Find it again, anywhere
Notes follow you across devices and sessions — click the ball again, wherever you are.
Setup

Install and start jotting notes

1
Install the module
Copy the module into your Odoo 19 addons path, update the app list, then install Sticky Notes from Apps.
2
No configuration needed
The floating ball appears immediately for every internal user — nothing to set up first.
3
Click the ball and start writing
Add your first note, pick a colour, and pin it if it matters. That's the whole setup.
