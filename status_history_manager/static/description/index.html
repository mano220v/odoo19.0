Overview

What does this module do?

Every time an employee changes a Status, Price, Quantity, or Discount on a Purchase Order, Sales Order, or Stock Transfer, the module records it automatically. No setup. No configuration. Just install and it works.

Example: Arjun Sharma changed the Unit Price of "Dell Laptop 14in" on PO/2025/0042 from $1,200.00 to $1,050.00 on 25 May 2025 at 11:15 AM.

Setup

How to use it

1
 Install the module - no configuration required.
2
 Open any Purchase Order, Sales Order, or Inventory Transfer.
3
 Click the Change History tab in the notebook.
4
 Review the complete colour-coded log of all changes made by your team.
5
 Use the Change History menu under Purchase / Sales / Inventory for a global view.
FAQs

Frequently asked questions

What changes are tracked?
Status, price, quantity, discount, and selected One2many line-level changes for supported records.
Do I need to write Python code?
No. The module works after installation without custom code for each tracked model.
Where can users review the data?
Changes appear in the notebook tab and also in the global history menu for reporting.
Does it support line-level changes?
Yes. Selected One2many child-line changes are recorded on the parent record.
