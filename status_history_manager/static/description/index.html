Overview

Field Tracker History Management records important document changes automatically. Every modification is logged with the user, date, time, previous value and new value.

✓ Purchase Orders

Track price, quantity and status changes.

✓ Sales Orders

Track discount, price and quantity updates.

✓ Inventory Transfers

Track stock movement and quantity changes.

✓ Global Audit Logs

Review all activity from centralized menus.

Example: John Smith changed the Unit Price from $1200.00 to $1050.00 on 25 May 2025 at 11:15 AM.

How To Use

  1. Install the module.
  2. Open a Purchase Order, Sales Order or Inventory Transfer.
  3. Modify status, quantity, price or discount values.
  4. Save the document.
  5. Open the Change History tab.
  6. Review detailed audit information.
  7. Use the global Change History menu for reporting.

Frequently Asked Questions

What changes are tracked?

Status, quantity, price, discount and configured line-level changes.

Do I need additional configuration?

No. The module works immediately after installation.

Can users see change history from documents?

Yes. History is available directly inside supported documents.

Does it support line-level tracking?

Yes. One2many line changes can be recorded and displayed.
