Overview

What does this module do?

Every time an employee changes a Status, Price, Quantity, or Discount on a Purchase Order, Sales Order, or Stock Transfer, the module records it automatically. No setup. No configuration. Just install and use.

Example: Arjun Sharma changed the Unit Price of “Dell Laptop 14in” on PO/2025/0042 from $1,200.00 to $1,050.00 on 25 May 2025 at 11:15 AM.

How to use

Simple installation and use

No complicated setup. Install the module and start checking change history from the relevant forms or from the global menu.

Install the module — no configuration required.
Open any Purchase Order, Sales Order or Inventory Transfer.
Click the Change History tab in the notebook.
See the complete, colour-coded log of all changes made by your team.
Use the Change History menu under Purchase / Sales / Inventory for a global view.

FAQ

Frequently asked questions

What changes are tracked?
It tracks status, price, quantity, discount, and selected line-level changes for Purchase, Sales, and Inventory records.
Do I need to write Python code?
No. The module is designed to work after installation, without custom code for each tracked model.
Where can users review the data?
Users can review changes directly in the notebook tab and also in the global Change History menu for search and filtering.
Does it support line-level changes?
Yes. Selected line changes are recorded so the audit trail stays complete for operational review.
