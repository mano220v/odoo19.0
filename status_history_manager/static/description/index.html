Field Tracker History Management

Complete audit trail for Purchase Orders, Sales Orders and Inventory Transfers. Track every status, quantity, price and discount change automatically.

Odoo 19 Community & Enterprise

⚙ Automatic Tracking

No configuration required after installation.

🕒 Change History Tab

View audit records directly inside documents.

🌐 Global History Menu

Search and review all tracked changes.

📋 Line-Level Audit

Track quantity, price, status and discount changes.

Overview

Every time a user modifies:

  • Status
  • Quantity
  • Price
  • Discount

the module automatically records the old value, new value, user and timestamp.

Example: Arjun Sharma changed Unit Price from $1200.00 to $1050.00 on 25 May 2025 at 11:15 AM.

Setup

  1. Install the module.
  2. Open Purchase, Sales or Inventory documents.
  3. Perform updates.
  4. Review the Change History tab.
  5. Use the global history menu for reporting.

Frequently Asked Questions

What changes are tracked?

Status, quantity, price and discount changes.

Is configuration required?

No. The module works immediately after installation.

Does it support line-level tracking?

Yes.
