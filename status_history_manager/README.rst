Field Tracker History Management
=================================

Track every status, price, quantity and discount change across
Purchase Orders, Sales Orders and Inventory Transfers.

Features
--------
* Automatic logging — no configuration needed
* Employee name, changed field, from/to values recorded
* One2many "Change History" tab on Purchase, Sale and Stock Picking forms
* Global history menus under Purchase, Sales and Inventory apps
* Color-coded log entries by change type
* Supports Odoo 19

Installation
------------
1. Copy the ``status_history_manager`` folder to your Odoo addons path.
2. Update the Apps list.
3. Install **Field Tracker History Management**.
